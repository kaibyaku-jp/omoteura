# Security Policy

## Supported versions

Only the latest released minor version of Omoteura receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/kaibyaku-jp/omoteura/security/advisories/new) of this repository.

We aim to acknowledge reports within 5 business days.
